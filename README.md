# Adopt Buddy - Pet Adoption Platform

Adopt Buddy is a full-stack MERN application designed to connect loving homes with pets in need. It provides a platform for shelters to post adoptable pets and for adopters to browse, apply, and chat with shelters in real-time.

## Features

- **Role-Based Access:** Separate dashboards and features for Adopters and Shelters.
- **Real-Time Chat:** Integrated Socket.IO for instant communication between adopters and shelters.
- **Pet Listings:** Browse, search, and filter pets by species.
- **Adoption Requests:** Adopters can send requests; shelters can approve or reject them.
- **Secure Authentication:** JWT-based auth with HTTP-only cookies (Access & Refresh tokens).
- **Image Uploads:** Cloudinary integration for pet and user profile pictures.
- **Responsive Design:** Mobile-first UI built with Tailwind CSS.

## Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, React Router, Axios, Socket.IO Client
- **Backend:** Node.js, Express, MongoDB (Mongoose), Socket.IO, JWT, bcryptjs
- **Storage:** Cloudinary (via Multer)

## Prerequisites

Before you begin, ensure you have met the following requirements:
- Node.js (v18 or higher)
- A MongoDB Atlas account and connection string
- A Cloudinary account (Cloud Name, API Key, API Secret)

## Environment Variables

Create a `.env` file in the root directory and add the following variables (see `.env.example`):

```env
MONGODB_URI="your_mongodb_connection_string"
JWT_ACCESS_SECRET="your_jwt_access_secret"
JWT_REFRESH_SECRET="your_jwt_refresh_secret"
CLOUDINARY_CLOUD_NAME="your_cloudinary_cloud_name"
CLOUDINARY_API_KEY="your_cloudinary_api_key"
CLOUDINARY_API_SECRET="your_cloudinary_api_secret"
NODE_ENV="development"
APP_URL="http://localhost:3000"
```

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run the Development Server:**
   ```bash
   npm run dev
   ```
   This will start both the Express backend and the Vite frontend concurrently.

3. **Build for Production:**
   ```bash
   npm run build
   ```

4. **Start Production Server:**
   ```bash
   npm start
   ```

## Deployment

This application is configured to run as a single full-stack service. The Express server serves the API routes and also serves the static files generated by Vite in the `dist` folder.

### Render / Vercel Deployment
1. Set the Build Command to `npm run build`
2. Set the Start Command to `npm start`
3. Add all the required Environment Variables in the hosting provider's dashboard.

## Docker Setup (Optional)

You can containerize the application using Docker. Create a `Dockerfile`:

```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

Build and run:
```bash
docker build -t adopt-buddy .
docker run -p 3000:3000 --env-file .env adopt-buddy
```
